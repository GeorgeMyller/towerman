# Towerman

Liga os terminais do IDE ao [Towerman](https://github.com/GeorgeMyller/towerman), a torre de controlo dos agentes de IA (Claude Code, Codex e Antigravity).

## O que faz

- **Focar:** traz para a frente a janela e o terminal da sessão que escolher no Mac, no iPhone ou no Apple Watch.
- **Responder:** escreve no terminal da sessão o texto que mandar a partir do painel.

## Instalação

O `towerman install` instala esta extensão em todos os IDEs da família VS Code que encontrar. As janelas já abertas ficam ligadas depois de recarregar.

A extensão só fala com o `towerman serve` deste computador (`127.0.0.1`), com o token em `~/.claude/towerman/token`.
